# Python Starter

Мої конспекти та розв'язані завдання з курсу **Python Starter**.
Тут зібрано все, що я вивчила: від змінних до обробки винятків.

## Зміст

| Файл | Що всередині |
|------|--------------|
| [`01_variables_and_loops.py`](01_variables_and_loops.py) | змінні, f-рядки та конкатенація, цикли `while` / `for`, `break` / `continue`, робота з рядками, числа Фібоначчі |
| [`02_lists.py`](02_lists.py) | списки: перебір, максимум, піднесення до квадрата, видалення елементів, паліндром |
| [`03_dictionaries.py`](03_dictionaries.py) | словники: способи створення, методи (`get`, `pop`, `update`, `setdefault`...), підрахунок повторів |
| [`04_sets_and_tuples.py`](04_sets_and_tuples.py) | множини та їхні операції, кортежі, розпакування, swap змінних |
| [`05_functions.py`](05_functions.py) | функції: аргументи, `*args` / `**kwargs`, `return`, область видимості (LEGB), `lambda`, рекурсія |
| [`06_exceptions.py`](06_exceptions.py) | `try` / `except` / `else` / `finally`, `raise`, власні винятки, `assert` |

## Як користуватися

Більшість прикладів закоментовано, бо я запускала їх по одному під час навчання.
Щоб запустити приклад, розкоментуйте потрібний блок (у PyCharm: виділити код і `Ctrl + /`, на Mac `Cmd + /`) і виконайте:

```bash
python 01_variables_and_loops.py
```
